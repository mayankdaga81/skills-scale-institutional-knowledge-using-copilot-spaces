# OctoAcme Project Management Docs

This README centralizes OctoAcme's project management process documents and provides a brief overview of the core processes used across projects.

## Project management processes summary

- Initiation: define the problem, stakeholders, success metrics, and go/no-go decision before planning begins.
- Planning: prioritize the backlog, estimate scope, define acceptance criteria and Definition of Done, and identify dependencies and risks.
- Execution & Tracking: run daily standups, use a project board, review PRs with CI checks, and track milestone progress through regular demos and updates.
- Release & Deployment: prepare release notes, run pre-release checks and smoke tests, deploy with a rollback plan, and confirm post-deploy verification.
- Retrospectives & Continuous Improvement: capture what went well, what needs improvement, and track action items to improve the team over time.
- Risk & Communication: maintain a risk register, share regular status updates, and escalate blockers through the defined project leadership path.
